OpenAI STT 하이브리드 전사 변경 내역

실시간 화면 표시는 Web Speech API를 유지하고, 답변 종료 시 MediaRecorder 오디오 chunk를 OpenAI STT로 전사하되 브라우저 전사문을 힌트로 함께 전달하도록 변경했습니다.

7

변경된 파일

3

주요 폴더

Hybrid

실시간 표시 + 최종 STT 보정

동작 흐름

1

실시간 표시

브라우저 Web Speech API 결과를 즉시 화면에 표시합니다.

2

오디오 저장

MediaRecorder가 답변 음성을 chunk 단위로 백엔드에 전송합니다.

3

힌트 저장

각 chunk metadata에 브라우저 전사문과 언어 정보를 같이 보냅니다.

4

최종 STT

답변 종료 시 백엔드가 OpenAI STT를 호출해 오디오를 전사합니다.

5

최종 분석

OpenAI STT 결과를 최종 답변 텍스트로 사용하고, 실패 시 브라우저 전사로 대체합니다.

폴더별 변경 파일

components/screenpipe/realtime-audio.tsx Frontend
  • 오디오 chunk metadata에 browserTranscript, browserLatestText, language를 추가했습니다.
  • 답변 종료 버튼 또는 음성 명령으로 종료할 때 브라우저 전사문과 speech metrics를 백엔드에 함께 전송합니다.
  • 세션 answer turn이 바뀌거나 히스토리를 지울 때 브라우저 전사 ref도 초기화합니다.
context/InterviewSessionContext.tsx Frontend
  • AnswerFinishMetadata 타입을 추가했습니다.
  • finishAnswer가 browserTranscript, language, speechMetrics 같은 추가 데이터를 받을 수 있게 확장했습니다.
backend/app/api/sessions.py Backend
  • OpenAI STT 호출 로직을 추가했습니다.
  • STT prompt에 브라우저 전사문을 힌트로 넣되, 오디오와 충돌하면 오디오를 우선하도록 안내합니다.
  • OPENAI_API_KEY가 없거나 STT 실패 시 브라우저 전사문으로 fallback합니다.
  • audio chunk 저장 시 브라우저 전사문, 최신 인식 텍스트, 언어 정보를 Redis chunk 데이터에 함께 저장합니다.
  • 답변 종료 시 최종 answerText, browserTranscript, transcriptionSource, speechMetrics를 분석 데이터에 저장합니다.
backend/app/schemas/chunk.py Backend Schema
  • AudioChunkMetadata에 language, browserTranscript, browserLatestText 필드를 추가했습니다.
backend/app/schemas/session.py Backend Schema
  • AnswerFinishRequest에 browserTranscript, language, speechMetrics 필드를 추가했습니다.
backend/requirements.txt Dependency
  • Python 백엔드에서 OpenAI STT를 호출할 수 있도록 openai>=1.60,<2 의존성을 추가했습니다.
app/api/sessions/[[...path]]/route.ts Local Mock API
  • 로컬 Next.js mock session endpoint의 finish 응답에 브라우저 전사 기반 mock 값을 포함했습니다.

실행 전 확인 사항

실제 OpenAI STT를 사용하려면 백엔드 환경에 OPENAI_API_KEY가 설정되어 있어야 하며, backend/requirements.txt 기준으로 Python 패키지를 다시 설치해야 합니다. 키 또는 패키지가 없으면 앱은 브라우저 전사문 fallback으로 계속 동작합니다.
