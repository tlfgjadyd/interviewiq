현재 의도한 동작 흐름

1

세션 시작

Start Session 버튼으로 sessionId와 answerTurnId를 생성합니다.

2

오디오 스트림

마이크를 열고 MediaRecorder가 5초마다 audio chunk를 백엔드로 보냅니다.

3

실시간 피드백

SpeechRecognition 결과로 말하기 평가 카드만 갱신합니다.

4

답변 종료

버튼 또는 종료 키워드로 마지막 chunk를 flush하고 finish API를 호출합니다.

로컬 전용

버튼 역할 정리

  • Start Session: 면접 세션과 첫 answer turn을 생성합니다.
  • Start Audio Transcription Stream: 마이크, MediaRecorder, SpeechRecognition을 시작합니다.
  • 답변 종료 / Finish Answer: 마지막 audio chunk를 flush하고 현재 answer turn을 종료합니다.
  • 상단 Finish Answer는 혼선을 줄이기 위해 숨겼습니다.

백엔드 담당자에게 전달할 핵심

  • 5초 audio chunk endpoint에서는 OpenAI STT를 호출하지 말고 저장만 합니다.
  • STT와 정식 음성 분석은 /answers/{answerTurnId}/finish 시점에 answer 단위로 처리합니다.
  • STT 모델은 gpt-4o-mini-transcribe를 기본값으로 사용합니다.
  • 실시간 카드용 feedback은 프론트의 SpeechRecognition 결과와 OpenRouter API를 사용합니다.
  • 최종 꼬리질문/보고서는 백엔드가 audio chunks, STT 텍스트, speech metrics를 종합해 생성합니다.

주의사항

.env에는 실제 API 키가 들어갈 수 있으므로 GitHub나 ZIP 공유 대상에서 제외해야 합니다. 공유 시에는 실제 키가 없는 .env.example 형태로 변수명만 전달하는 것이 안전합니다.
